# Install and release

Codex Jet targets macOS 14 or later. The universal release supports Apple Silicon and Intel Macs. It uses ad-hoc code signing and is not notarized with an Apple Developer ID.

## Install or update

Download the latest `CodexJet-macOS-universal.zip` and `SHA256SUMS` from [GitHub Releases](https://github.com/StarrHuang/codex-jet/releases). Clone the public repository and run:

```sh
git clone https://github.com/StarrHuang/codex-jet.git
cd codex-jet
./scripts/install.sh
```

For an update, quit Codex Jet and rerun `./scripts/install.sh`. The script verifies the checksum, signature, and CPU architecture before replacing the app. It does not need `sudo`. App data and the existing Codex sign-in remain on the Mac.

Options:

- `--destination DIRECTORY` installs into a chosen directory.
- `--no-launch` installs without opening the app.
- `--archive PATH` installs a downloaded zip beside its `SHA256SUMS` file.

## Build and package

Use Xcode or Command Line Tools with Swift 6:

```sh
./scripts/build-app.sh
```

To build and package a universal release locally:

```sh
./scripts/build-app.sh --universal
./scripts/package-release.sh
```

The package is written under `dist/`. Release artifacts are generated by the GitHub Actions workflow when a version tag is pushed. The tag must match the version in `VERSION`.
